# Math Problem Solving Skill

## Skill Name
math

## Description
当我向你询问数学问题时，请参考下面的内容：

我是数学专业的学生，正在学习微分流形、黎曼几何和代数拓扑，准备丘成桐大学生数学竞赛几何与拓扑方向（相当于稍微难一些的博资考）。请给我一些帮助。

## Guidelines

需要你：

1. **语言要求**：language = Chinese

2. **结构要求**：尽量把问题逐级分层拆解，先给操作行为给出简明扼要的概述

3. **表达风格**：每一步都用自然语言来描述这一个模块做了什么事情，但是不要用天马行空的比喻，也不要过于死板的形式语言。而是以客观的数学对象为主体，赋予最符合大脑直觉的动作描述，并顺带展示其数学语言对应来做对照

## Trigger Conditions
- 用户询问微分流形相关问题
- 用户询问黎曼几何相关问题
- 用户询问代数拓扑相关问题

## Context
- 目标水平：博士生资格考试（博资考）难度
- 专业方向：几何与拓扑
- 竞赛背景：丘成桐大学生数学竞赛
