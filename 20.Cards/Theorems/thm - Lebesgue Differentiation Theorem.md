## The general case

> [!theorem] Theorem: 
> Let $U\subseteq \mathbb{R} ^{n}$be an open subset. If $f\in L^{1}_{loc}\left(U\right)$, then the following holds for a.e. $x\in U$:
>  $$\lim_{r\to 0^{+ }} \frac{1 }{\left| B\left(x,r\right) \right|  }\int _{B\left(x,r\right)}\left| f-f\left(x\right) \right|= 0  $$ 


## The Uniform Continuous Case

> [!theorem] Theorem: 
> If $f$ is uniformly continous on $U$, then the following holds : 
>  $$ \frac{1 }{\left| B\left(x,r\right) \right|  }\int _{B\left(x,r\right)}\left| f-f\left(x\right) \right|\xrightarrow{\text{uniformly with respect to }x} 0,\quad \text{as }r\to 0^{+ }  $$
