> [!corollary] Corollary: A map from compact to Hausdorff spaces is closed
> If $X$ is compact and $Y$ is Hausdorff, then every map $f: X \to Y$ is closed. In particular,
>
> - if $f$ is injective, then it is an embedding;
>
> - if $f$ is surjective, then it is a quotient map;
>
> - if $f$ is bijective, then it is a homeomorphism.
